# macros/

In-game macro palettes written out as text so they can be rebuilt after a reinstall or shared.
The game stores macros in `USER\<id>\mcr*.dat` binaries, which are not worth committing; the
readable form is. One file per job or purpose, e.g. `blm.md`, with book and set numbers noted
because the LuAshitacast profiles switch to them in `OnLoad`.
