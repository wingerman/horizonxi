# ashita-scripts/

Plain-text Ashita scripts. Install by copying into `Game\scripts\`; run in game with
`/exec <name>.txt`. One command per line, same syntax as the chat box. `default.txt` in that folder
runs at launch and is where Horizon loads its addons; put personal additions in the section its
comments mark, or in a separate file called from it.

Empty for now. Candidates: skill-up loops (enhancing, ninjutsu), a per-job bind set, `/fps 0`
and `/drawdistance setworld 4` as a graphics preset.
